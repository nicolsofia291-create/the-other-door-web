# the-other-door-web
Sitio web institucional de The Other Door con GitHub Pages

**Descripción**

The Other Door es un proyecto de videojuego en desarrollo centrado en una historia de búsqueda, exploración, acertijos y tensión emocional. La protagonista atraviesa un mundo alterno para encontrar a sus padres desaparecidos y recuperar los ojos de los niños atrapados por una criatura maligna.

**Tecnologías previstas**

Blender
Unity
Toon Shader
PBR materials
Adobe / herramientas de arte visual
Git + GitHub para control de versión

**Estado del proyecto**

Desarrollo inicial: 10 semanas
Tiempo ejecutado aproximado: 200 horas
Estado: prototipo / desarrollo activo
