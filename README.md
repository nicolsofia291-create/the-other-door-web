# The Other Door Web

Landing page del proyecto **The Other Door**, lista para publicarse en GitHub Pages.

## Publicar en GitHub Pages

1. Entra al repositorio `the-other-door-web` en GitHub.
2. Ve a **Settings** > **Pages**.
3. En **Source**, selecciona **Deploy from a branch**.
4. Escoge la rama `main`.
5. Selecciona la carpeta `/ (root)`.
6. Guarda.

URL esperada:
https://nicolsofia291-create.github.io/the-other-door-web/

## Contenido

La landing page incluye:
- hero con mensaje principal
- descripción del proyecto
- pipeline creativo
- galería de referencia
- equipo
- sección de apoyo
- formulario de contacto
